How to read this

Multi-policy vs single-item is counted per buyer from the item count on each bound sale, so it's exact. The by-source table uses GOAL's own Sold/Items pixels grouped by source — GOAL doesn't tag an individual policy with its source, so this is the platform's aggregate attribution, not a per-buyer join. "Prior carrier" is the existing coverage on the matched prospect record.
